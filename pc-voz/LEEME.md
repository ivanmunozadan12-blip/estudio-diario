

Las voces de referencia de cada personaje están en `voz-ref/` (yo, amigo, amiga, jefe, abuela, madre). Para cambiar una, sustituye su .wav (5-10 s, voz natural, sin ruido) y sube `PC_V` en `index.html` para regenerar las frases.

Para usar el PC con este motor, una vez: `venv\Scripts\pip install chatterbox-tts soundfile` (el entorno antiguo tenía qwen-tts).
