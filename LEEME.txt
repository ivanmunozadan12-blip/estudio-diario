ESTUDIO DIARIO — BEHIND DEL MUNDO
Automatización diaria: 3 vídeos a las 09:30, 14:30 y 20:30 (Europe/Madrid).

A) WEB (Netlify)
- La web permite generar guiones y vídeos manualmente.
- Los botones Descargar, Abrir y Compartir funcionan sobre el vídeo generado.
- El piloto automático de la web requiere mantener la página abierta; para la generación diaria se usa GitHub Actions.
- Service worker actualizado: no cachea las respuestas de las funciones Netlify ni las respuestas HTTP fallidas.

B) GENERACIÓN AUTOMÁTICA (GitHub Actions)
- GitHub Actions abre la web real en Chromium, elige los temas, investiga, redacta y verifica los guiones, genera la voz y graba los vídeos.
- Antes de gastar cuota Gemini, ejecuta comprobaciones de código y un preflight de Telegram y OAuth de YouTube.
- Los MP4 se convierten y se validan con FFprobe: deben tener imagen, audio, formato vertical 9:16, duración válida y pistas sincronizadas.
- Si los secretos de YouTube están configurados, los vídeos se publican automáticamente como públicos. Telegram recibe los vídeos y sus textos.
- La validación del repositorio se ejecuta en cada push y pull request. Comprueba sintaxis, JSON, YAML, shell, slots y el arranque de la web en Chromium. No llama a Gemini ni publica vídeos.
- Si una ejecución se repite (rerun), se omiten los envíos externos para evitar duplicados. Para reintentar una publicación fallida, inicia una ejecución nueva y revisa antes el historial para evitar repetir el contenido.

C) SECRETOS DE GITHUB
En Settings → Secrets and variables → Actions:
- GEMINI_API_KEY
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID
- GEMINI_API_KEY_2, GEMINI_API_KEY_3 y GEMINI_API_KEY_4 (opcionales; para cuotas independientes deben pertenecer a proyectos de Google distintos).
- YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET y YOUTUBE_REFRESH_TOKEN (opcionales; si se configuran los tres, se activa la publicación automática).

Para conectar YouTube:
1. En Netlify, configura YOUTUBE_CLIENT_ID y YOUTUBE_CLIENT_SECRET.
2. Abre la página /youtube-connect.html de la web desplegada y pulsa «Conectar con Google».
3. Registra en Google Cloud la URI de redirección exacta:
   https://glistening-cascaron-b5b987.netlify.app/.netlify/functions/youtube-callback
4. Guarda el refresh token que devuelve Google como secreto YOUTUBE_REFRESH_TOKEN en GitHub.
5. El preflight renueva el token antes de generar; no sube vídeos durante esa comprobación.

D) SECRETOS Y CONFIGURACIÓN DE NETLIFY
- YOUTUBE_CLIENT_ID y YOUTUBE_CLIENT_SECRET: necesarios para iniciar la conexión OAuth desde la web.
- GITHUB_HISTORY_TOKEN: token fine-grained de GitHub con acceso Contents: Read and write únicamente al repositorio ivanmunozadan12-blip/estudio-diario. Permite sincronizar el historial de temas desde la web.
- SITE_ORIGIN: opcional. Solo hace falta si la web se sirve desde otro origen distinto de https://glistening-cascaron-b5b987.netlify.app.
- No introduzcas tokens en el código fuente ni los compartas por chat.

E) EJECUTAR Y REVISAR
- Pestaña Actions → «Vídeos diarios» → Run workflow.
- Slot: 0, 1 o 2 para un vídeo; «all» para los tres. Si se deja vacío, el sistema calcula qué franja corresponde a la hora de Madrid.
- Los horarios de GitHub Actions son UTC y pueden retrasarse en horas punta. ci/slot.js evita ejecutar una franja ya registrada en history.json.
- Los errores y los pasos de cada ejecución aparecen en Actions. No se debe repetir a ciegas una ejecución que ya haya enviado un vídeo a Telegram o YouTube.
- Ajustes de nicho, duración y horario: config.json. La duración actual configurada es 60 segundos.

F) CUOTAS GEMINI
- Google aplica cuotas por proyecto, no por clave. Cuatro claves del mismo proyecto no multiplican la cuota.
- Las cuotas pueden incluir límites por minuto, tokens y día; varían por modelo y proyecto. Consulta aistudio.google.com/usage y aistudio.google.com/rate-limit.
- La rotación prueba proyectos alternativos si falla la detección de modelos, se agota la cuota o se produce un error temporal de conexión.
- Las pruebas automáticas del repositorio no consumen cuota Gemini. El preflight consulta Telegram y OAuth de YouTube, pero nunca genera ni publica contenido.
